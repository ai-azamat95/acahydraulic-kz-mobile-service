# ACA Hydraulic KZ — Mobile Service Website

Отдельный репозиторий сайта `acahydraulic.kz`.

Назначение: выездной сервис по ремонту гидравлики и спецтехники в Казахстане.

## Важно

Это экспорт/исходники сайта из Manus, вынесенные в отдельный репозиторий, чтобы не путать с другими ACA-проектами:

- `acahydraulic.com` — продажа/подбор б/у ГНБ из Китая
- `acahdd.kz` — услуги ГНБ
- `acahydraulic.kz` — выездной сервис и ремонт спецтехники

## Локальная разработка

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Статический фронтенд собирается в `dist/public`.
