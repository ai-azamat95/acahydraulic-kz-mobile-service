## JavaScript-цели

Код сайта отправляет только существующие контактные микроконверсии:

| Идентификатор цели            | Событие                                        |
| ----------------------------- | ---------------------------------------------- |
| `acahydraulic_whatsapp_click` | общий переход в WhatsApp                       |
| `acahydraulic_phone_click`    | нажатие на номер телефона                      |
| `catalog_whatsapp_click`      | запрос товара из каталога                      |
| `case_whatsapp_click`         | переход в WhatsApp из кейса                    |
| `form_whatsapp_click`         | открытие WhatsApp после формы или калькулятора |

Это контактные намерения. Они не подтверждают получение сообщения, квалифицированную заявку, заказ, выручку или прибыль. Текст WhatsApp, телефон, email, VIN и свободные поля формы в параметры целей не передаются.

Для подсчёта целей в кабинете Яндекс.Метрики в счётчике `109131701` должны существовать цели типа «JavaScript-событие» с теми же идентификаторами. Наличие вызова `reachGoal` на сайте не доказывает, что цели уже созданы или получают данные в кабинете.
