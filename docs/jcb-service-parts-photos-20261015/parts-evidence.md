## Уточнения и границы доказательств

### 32/925346

- Назначение: Сменный фильтрующий элемент гидравлической системы.
- Подтверждение JCB: Hydraulic Filter Element — https://parts.jcb.com/uk/product/32-925346
- Пользовательское фото: 2-Фото-2.jpg; читается: 32/925346; FILTER ELEMENT.
- Граница: Тип гидравлического фильтра подтвержден JCB; не уточнять линию, тонкость фильтрации или размеры без каталога конкретной машины.
- Применяемость: JCB 3CX; https://parts.jcb.com/uk/machine-parts/jcb-backhoe-loader-parts/3cx-parts; Код перечислен на общей странице 3CX; требуются PIN, год и исполнение. Это не универсальная совместимость.

### 32/925682

- Назначение: Наружный основной элемент воздушного фильтра двигателя.
- Подтверждение JCB: ELEMENT-AIRPQ145 — https://parts.jcb.com/uk/product/32-925682
- Пользовательское фото: 3-Фото-3.jpg; читается: 32/925682; MAIN ELEMENT.
- Граница: Воздушное назначение подтверждено JCB; наружный подтвержден exact SIF карточкой; основной — маркировкой пользовательского фото.
- Дополнительный первичный источник: https://onlinesatis.sif.com.tr/32925682-havalandirma — Наружный воздушный фильтр (DIŞ HAVA FİLTRESİ).
- Применяемость: JCB 3CX / 4CX / 5CX / TH; https://onlinesatis.sif.com.tr/32925682-havalandirma; Только широкие семейства, перечисленные SIF. Не использовать как гарантию установки; точное исполнение определяется PIN.

### 32/925683

- Применяемость: JCB 3CX / 4CX / 5CX / TH; https://onlinesatis.sif.com.tr/32925683-havalandirma; Только широкие семейства SIF; не универсальная совместимость.

## Рекомендуемая публикация

- Статус: «Цена, наличие и срок поставки — по запросу».
- Подбор: каталожный номер, PIN / серийный номер, фото шильдика; перед заказом сверка исполнений.
- Не выдавать фото упаковок за доказательство оригинальности, локального склада или официального дилерства ACA.
- Не обещать комплектацию 813/50012 из двух уплотнений: у фото и JCB страницы различается единица упаковки.
- Публичное «грубой/тонкой очистки» можно не использовать: JCB уверенно подтверждает 320/A7124 как элемент первичного фильтра через сборку 320/A7116, для 320/A7170 в этом проходе подтвержден нейтральный Fuel Filter Element.
- SIF источник внешнего/внутреннего воздушных элементов: точные product pages. Категория/модельное семейство SIF не заменяет проверку по PIN.
