# JCB: восемь сервисных деталей по пользовательским фотографиям

Дата проверки: 15 октября 2026 года. Эти материалы — внутренняя история происхождения данных. Файлы этой папки не копируются в `client/public` или `dist/public`.

Пользователь предоставил десять JPEG. Восемь читаемых артикулов добавляются отдельными карточками; два общих снимка используются в галерее 581/R5206. Первичные источники JCB и точные карточки SIF подтверждают назначение номеров. Фотографии упаковки сами по себе не подтверждают подлинность партии, наличие на складе ACA, единицу продажи, срок поставки или официальное дилерство ACA.

Все публичные копии находятся в `/catalog-assets/jcb-service-parts/`. `photo-manifest.json` содержит SHA256 и размер в байтах каждого исходного JPEG до копирования. Файлы сохраняются без перекодирования; тест проверяет байтовое совпадение публичных копий с этими зафиксированными хешами.

`parts-evidence.json` и `parts-evidence.md` — копии отчёта исследования из `/tmp/aca-jcb-photo-evidence/`. В них сохранены точные ссылки JCB/SIF, прочитанные маркировки и ограничения доказательств. Они не являются публичным коммерческим предложением.

Условия карточек: цена, наличие и срок по запросу; совместимость проверяется по полному артикулу и PIN / серийному номеру машины. Для 320/A7124 наличие датчика воды, стакана или другого оборудования сборки 320/A7116 не обещается. Для 813/50012 не заявляется комплект из двух уплотнений: `QTY 2` на фото и `Pack Size 1` у JCB не устанавливают согласованную единицу продажи. Возможный нижний номер 813/50011 на фото 10 недостаточно читается и отдельной карточкой не публикуется.
