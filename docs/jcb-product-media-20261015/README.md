# JCB: фотографии деталей и видео осмотра

Дата: 15 октября 2026 года. Внутренние материалы происхождения данных; эта папка не относится к публичным ассетам сайта.

`source-manifest.json` фиксирует исходные семь JPEG и три MOV: имя, размер в байтах и SHA256. Хеши сверены непосредственно с пользовательскими оригиналами, а для фотографий и видео — также с отчётами исследования. MOV сохраняются как источник происхождения; публикуемые MP4 и постеры учитываются отдельно после проверки конечных файлов.

`filter-photos.json` / `.md`, `heavy-parts.json` / `.md` и `video-parts.json` / `.md` сохраняют результаты чтения маркировок, первичные источники и границы допустимых утверждений.

Фото 3 остаётся только во внутреннем `excluded/photo-3-unidentified-packaging.jpg`: читаемый артикул отсутствует. Внешнее сходство с другими коробками не доказывает номер детали.

Фотографии упаковок и видеозаписи не подтверждают складской остаток ACA, местонахождение товара, подлинность партии, новое состояние, согласованную комплектность, цену или официальный дилерский статус ACA. Эти сведения подтверждаются для конкретного предложения.

Для фильтров используются существующие карточки 581/R5206, 320/A7227, 320/B4420, 32/925682 и 32/925683. Фото 5 показывает сам элемент 32/925682; прежнее фото упаковки сохраняется. Общий снимок с несколькими номерами описывается как снимок нескольких упаковок и не доказывает единый комплект.

В белой этикетке фото 7 читается **400/G6382**; это [Slew Ring Bearing в каталоге JCB](https://parts.jcb.com/uk/product/400-G6382). Вариант чтения G6582 отклонён. Фото 6 не содержит надёжно прочитанного номера самого редуктора: допустим только подбор без подтверждённого бренда и OEM/MPN, без объявления его финальным приводом.

Первоначальное сомнение в 991/20023 снято дополнительными читаемыми кадрами видео 9; тот же ролик подтверждает 991/20021. Общее название Universal Seal Kit не означает совместимость с любым узлом. Источники и точные кадры перечислены в `video-parts.json`.

Для теплообменника из видео 10 установлен текст A4173 и видимый литой логотип JCB. Публикуется описательная карточка с обозначением «маркировка A4173», без полного OEM/MPN. Официальный кандидат 320/A4173 не считается прочитанным номером экземпляра.

`publication-manifest.json` фиксирует 16 конечных файлов: шесть исходных JPEG, четыре кадра, три постера и три MP4. Каждый файл связан с исходным фото или MOV и точными карточками. Все файлы локальные; фото 3 в публикацию не входит. Видео перекодированы без кадрирования и обрезки, без звуковой дорожки, в H.264/yuv420p с `faststart`; полная проверка декодирования зафиксирована в `video-analysis.json`.

991/20038 уверенно читается на упаковке в видео. Общее назначение seal kit дополнительно найдено в первичном каталоге JLG с точным cross-reference; заводская карточка JCB для него не подтверждена. Это не основание заявлять оригинальность JCB или конкретное применение.

Видео открываются по действию пользователя: `controls`, `playsinline`, `preload="none"`, без автоматического воспроизведения. Шесть карточек используют три общих файла MP4; разные детали в одном ролике не объявляются единым комплектом или взаимозаменяемыми.

Проверка исходных и опубликованных файлов: `node --test tests/jcb-product-media.test.mjs`.
