# Карточка KPM K3VG280DT

Подготовлена по четырём фотографиям владельца. На шильдике читается KPM, поэтому перестановка букв KMP из запроса исправлена. В карточке используется только подтверждённая базовая модель K3VG280DT. Полный суффикс исполнения не перенесён из фотографии: его нужно отдельно сверить по читаемому шильдику перед подбором. Серийный номер не используется как артикул.

## Применяемость и источники

- [Kawasaki Precision Machinery: K3VG](https://www.kawasakihydraulics.com/product/k3vg/) описывает промышленное применение серии с большим расходом.
- [KPM USA: Hydraulic Pumps](https://www.kpm-usa.com/products/hydraulic-pumps/) отдельно перечисляет K3VG280DT в промышленной серии K3VG и K3V280DTH в серии для строительной техники.
- [KPM: монтажные чертежи K3VG280](https://www.kpm-eu.com/Products/K3V/Installation-Drawings/K3VG-2D-Installation-Drawings/K3VG280-K3VG280DT.aspx) относит K3VG280DT к тандемным насосам и различает исполнения регуляторов.

Источники проверены 8 ноября 2026 года. Конкретная модель машины для данного исполнения не подтверждена. Поэтому не перенесены CAT 385C/390D, Hitachi ZX850/ZX870 или Volvo EC700BLC из похожих существующих карточек K3V280. Названия K3V280 и K3VG280DT не объединяются. Фотография шильдика не доказывает подлинность или происхождение предлагаемого изделия.

## Содержание

Одна карточка в категориях «Гидронасосы» и «Аксиально-поршневые насосы», брендовая навигация Kawasaki, четыре неизменённых исходных JPEG. Цена по запросу, наличие не заявлено. Нет обещаний срока, гарантии, оригинальности или определённого состояния. Инструкция подбора требует полный код, модель и серийный номер оборудования, вращение, вал, фланец, порты и регулятор.

Цена хранится как null. Число 0, фиктивные Offer/InStock и Product schema для карточки без цены не создаются. Дата 2026-11-08 относится только к новой проверенной карточке. Другие товары и фотографии не меняются.

## Проверка и публикация

Тест tests/kpm-k3vg280dt-product.test.mjs проверяет идентичность, отсутствие неподтверждённых заявлений, хеши фотографий, поиск, обе категории, статический HTML, canonical, sitemap и отсутствие ценового предложения. Перед тестом требуются build и catalog:routes. Публичные JSON обновлены штатным prepare-public-catalog и включены в ветку, чтобы карточка работала без дополнительного импорта.

Черновик PR предназначен для просмотра владельцем. Слияние и публикация не входят в это изменение. При объединении с другой новой карточкой нужно повторно выполнить prepare-public-catalog, а не вручную соединять минифицированные снимки каталога.
