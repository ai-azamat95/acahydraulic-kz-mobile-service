# Мобильная шапка каталога: прокрутка и меняющийся viewport

Основание: поручение исправить смещение из `IMG_5159.jpeg` и сразу опубликовать отдельное исправление после проверок. База — актуальный `main`, `96c9ef90b569a424580ea72a0865e1f1f7d11e97` (после PR #192). PR #189 и #190 остаются отдельными черновиками и сюда не включены.

## Наблюдение и границы воспроизведения

Пиксели исходного скриншота просмотрены: над двумя верхними панелями виден фрагмент товарной карточки при показанной компактной панели iOS. Нижняя плавающая иконка — открытие настроек cookie, не фильтры.

В исходном коде быстрая навигация имела `position: fixed`, а шапка каталога — `position: sticky` с отступом 48 px. Отсутствие навигации в потоке компенсировалось `padding-top: 48px` у соседнего контейнера. Исправление устраняет смешение этих способов позиционирования и учитывает меняющийся верхний safe-area inset.

Обычная прокрутка в desktop/mobile-emulated Chromium и WebKit **не воспроизвела сам нативный сдвиг панели Safari**: до исправления измерялись `top=0/48px`. На этом Mac нет iOS Simulator/подключённого управляемого iPhone. Поэтому реальная анимация родной панели Safari на устройстве не заявляется как проверенная. Автоматизация проверяет поток, геометрию, изменение viewport и эмулированные safe-area; исходный CSS не проходит проверку резервирования строки навигации.

## Изменение

Только CSS для страниц с `.aca-catalog-header` при ширине до 1023 px:

- быстрая навигация закрепляется через `sticky` и занимает собственную строку в потоке;
- прежний компенсирующий верхний padding убран;
- высота навигации, её внутренний верхний отступ и положение шапки используют один `safe-area-inset-top`.

Без верхнего inset размеры и внешний вид сохраняются. Desktop от 1024 px, товарные карточки, фотографии, цены, наличие, SEO-тексты, конверсии и настройки согласия не менялись. Нижняя кнопка cookie не перерабатывалась; проверено её отсутствие перекрытия с нижней навигацией. Существующее наложение плавающих элементов на прокручиваемый контент не выдаётся за новую функцию исправления.
