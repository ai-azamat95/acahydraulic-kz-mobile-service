# ACA Hydraulic — массовый импорт каталога

Каталог строится из файла `client/src/data/catalog.generated.json`. Его не нужно заполнять вручную: файл генерируется из CSV скриптом `scripts/import-catalog-csv.mjs`.

## 1. Подготовить CSV

Шаблон: `data/catalog-import-template.csv`.

Обязательные поля:

- `sku` — артикул / внутренний SKU;
- `title` — название товара;
- `brand` — бренд детали или производителя;
- `category` — категория.

Рекомендуемые поля:

- `slug` — URL-часть; если пусто, создаётся из SKU;
- `oem` — OEM-номера через `|`;
- `machineModels` — модели техники через `|`;
- `description` — оригинальное описание ACA Hydraulic;
- `image` — URL или путь к изображению;
- `sourcePrice` — закупочная цена;
- `sourceCurrency` — `CNY`, `USD` или `KZT`;
- `exchangeRateKzt` — курс одной единицы исходной валюты в тенге для конкретной строки;
- `markupPercent` — наценка, если отличается от общей;
- `priceKzt` — готовая цена в тенге. Если указана, автоматический расчёт не применяется;
- `availability` — `in_stock`, `on_request`, `out_of_stock`;
- `featured` — `true/false`;
- `isDemo` — `true/false`.

## 2. Импорт с наценкой +50%

Для товара в CNY:

```bash
node scripts/import-catalog-csv.mjs data/products.csv --markup=50 --cny-rate=70
```

Формула:

```text
цена KZT = закупочная цена × курс KZT × 1.50
```

Курс передаётся при каждом импорте, поэтому в коде сайта не фиксируется устаревающий валютный курс.

Для смешанного файла можно указать оба курса:

```bash
node scripts/import-catalog-csv.mjs data/products.csv --markup=50 --cny-rate=70 --usd-rate=540
```

Если в строке указан `exchangeRateKzt`, он имеет приоритет над общим курсом. Если заполнен `priceKzt`, он имеет приоритет над автоматическим расчётом.

## 3. Что проверяет импортёр

- наличие обязательных полей;
- допустимую валюту;
- уникальность `slug` и `id`;
- корректность числовых значений;
- автоматическую подстановку `on_request`, если статус неизвестен;
- автоматическую генерацию базового описания, если описание отсутствует.

## 4. SEO и публикация

Демо-позиции отмечаются `isDemo=true` и получают `noindex`. Реальные карточки должны публиковаться только после проверки:

1. OEM / артикула;
2. применяемости;
3. фотографии;
4. закупочной и розничной цены;
5. наличия / срока поставки;
6. оригинального описания.

Не следует массово копировать описания стороннего магазина. Технические атрибуты можно нормализовать, а коммерческие тексты и SEO-описания должны быть собственными.

## Следующий уровень масштабирования

До нескольких тысяч позиций этот пайплайн подходит для быстрого запуска. При росте каталога дальше товары следует перенести в серверную базу данных с пагинацией и поисковым индексом, сохранив тот же формат карточки и импорта.
