# Каталог: бренды, модели и связанные разделы — 5 октября 2026

## Запрос и границы

Запрос пользователя: «Что по сео? Нужно прокачать каталог». Linear issue не предоставлена. Изменение ограничено навигацией существующего каталога. Данные товаров, применяемость, цены, наличие, платежи, реклама и конверсии не меняются. Открытые PR других задач не объединяются.

## Проверенные проблемы

- В sitemap опубликованы 10 402 карточки и 249 посадочных: 20 категорий, 19 брендов, 210 моделей с минимум 8 позициями. Это число URL, не доказательство индексации Google.
- Исходный HTML `/catalog/` не содержал ссылок на бренды и модели.
- Три модели не имели входящих ссылок из других посадочных: SK140-8 (10 позиций), D905 (9), PC200-8M0 (8).
- React показывал одинаковые глобальные top-30 моделей на разных разделах. Статические related blocks содержали 1 023 ссылки на модели и 1 477 ссылок на бренды без общих товаров с текущим разделом.

## Решение

- Справочник всех опубликованных брендов и моделей на главной каталога, с группировкой моделей по марке и раскрывающимися списками.
- Одинаковый набор целевых URL в HTML без JavaScript и интерактивной странице.
- Модели на внутренних страницах отбираются по общим позициям с текущим разделом. Self links исключаются.
- Статические рекомендации категорий, брендов и моделей больше не включают нулевые пересечения.
- Для Isuzu/Hino/Kubota не создаются несуществующие brand URLs: сохраняются только опубликованные model URLs.
- Число карточек и sitemap URL не увеличено. Навигация не считается подтверждением совместимости.

## Проверки

- `pnpm check`, `pnpm build`.
- Генерация SPA, case, product и landing routes.
- `node --test tests/catalog-directory.test.mjs tests/catalog-navigation-ux.test.mjs tests/catalog-selection-guides.test.mjs tests/catalog-product-seo.test.mjs`: 17 тестов.
- `pnpm catalog:verify-seo` и `pnpm catalog:verify-landings`: 10 402 карточки, 249 разделов.
- Browser journey: все 229 brand/model ссылок совпадают с generated index, переход к D905, контекст Cummins, единственный canonical, отсутствие горизонтального переполнения, режим без JavaScript. Скриншоты: `catalog-ui-check/directory-*.png`.
- Регрессии добавлены в PR CI и workflow публикации. Все внешние запросы браузерных тестов блокируются; реальные контактные события не отправляются.
- Независимый review: замечание о Wouter hash navigation устранено; прочих блокирующих замечаний нет.

## Что ещё ограничивает SEO

Фактическая индексация и динамика органики не подтверждены: HYPD GSC вернул пустой список свойств, GSC Wizard требует активной подписки, Supermetrics GSC не авторизован. Новые подписки и оплаты не оформлялись. Следующий приоритет — авторизованное чтение Search Console и отбор коммерческих карточек по реальным запросам, затем проверенная русская номенклатура/OEM и обратные ссылки карточка → бренд/модель.

Основание для структуры: [Google Search Central — структура интернет-магазина](https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure) и [URL и обычные HTML-ссылки](https://developers.google.com/search/docs/specialty/ecommerce/designing-a-url-structure-for-ecommerce-sites). Рост позиций или продаж пока не измерен.
