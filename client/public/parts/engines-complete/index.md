# Двигатели в сборе для спецтехники

> Подбор исполнения и поставка двигателя в сборе после проверки шильдика, комплектации и условий заказа.

ACA Hydraulic принимает запросы на двигатели Cummins и другие двигатели для спецтехники. Для подбора нужны модель машины, модель двигателя, серийный номер, фото шильдика, требуемая комплектация и сведения о навесном оборудовании.

Совпадение серии двигателя не подтверждает совместимость. До оплаты согласуются точное исполнение, комплектность, состояние, цена, срок, доставка, монтаж и гарантийные условия. Доступность каждой позиции проверяется отдельно.
